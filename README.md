ProjekKantin

ProjekKantin adalah project sederhana untuk mengelola data kantin menggunakan sistem CRUD.

Fitur
Menampilkan data
Menambahkan data
Mengedit data
Menghapus data
Teknologi
PHP
MySQL
HTML
CSS
Cara Menjalankan
Clone repository:
git clone https://github.com/Ryanajaaa/ProjekKantin.git
Masukkan project ke folder htdocs jika menggunakan XAMPP.
Jalankan Apache dan MySQL di XAMPP.
Buka project melalui browser:
http://localhost/ProjekKantin
